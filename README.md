# Cielo Nail Studio · instaladores

Aquí se publican las versiones de **Cielo Nail Studio**, el sistema de gestión del estudio. Este repositorio **no contiene código ni datos**: solo los instaladores.

- Cada versión trae el instalador `CieloNailStudio-Setup-<versión>.exe` y el archivo `cielo-update.json`, firmado digitalmente.
- Cielo consulta este repositorio para avisar cuando hay una versión nueva, y solo instala archivos con una firma válida de Cielo Nail Studio.
- Para instalar por primera vez, descarga el instalador de la [versión más reciente](https://github.com/CieloNailStudio/cielo-releases/releases/latest). Si Windows muestra «Windows protegió tu PC», elige «Más información» y luego «Ejecutar de todas formas».
